## What I found reading the code

These come from reading it, not running it. Several directly break the "trustworthy results" goal:

- **Data leakage:** in `ml_engine.py:487-502`, missing-value filling, category encoding and the scaler are all fitted on the full dataset before the train/test split, so the test rows influence the training.
- **Mislabelled metrics on small datasets:** under 50 rows (`ml_engine.py:533-557`), accuracy and R² come from cross-validation, but F1, precision, recall, MSE and RMSE are scored on the same rows the model was trained on. All of them are shown together as one result.
- **Silent algorithm swaps:** any algorithm name the code doesn't recognise trains a Random Forest under the requested name (`ml_engine.py:408`). That includes XGBoost when it isn't installed, and LLM-recommended algorithms that aren't implemented.
- **Wrong model types:** for regression, "Naive Bayes" returns a classifier and "Logistic" returns `LogisticRegression`, which fails on a continuous target.
- **Settings ignored:** `hyperparameters`, `validation_split` and `random_state` are accepted by the API and then never used.
- **Missing targets:** rows with no target value aren't dropped. For text targets they become a `"nan"` class. With a rare class, the cross-validation can crash.
- **Wrong encoding for some models:** text categories are numbered 0, 1, 2…, which gives a false order to linear, KNN and SVM models.
- **Target choice:** the LLM picks the target column and task type when a Groq key is set. Without the key, the "recommend algorithm" step fails with a server error.
- **Leaky sample data:** `data/iris.csv` keeps its `Id` column as a feature. The rows are sorted by species, so `Id` alone predicts the answer.
- **Fake progress:** the percentages are hard-coded numbers with `sleep` calls in between.
- **Training blocks the server:** model fitting runs inside the server's async event loop, so nothing else responds while it trains.
- **Training updates can be missed:** they go to every connected client, and the page only connects after training has started. If it connects late, the screen can stay on "training" forever.
